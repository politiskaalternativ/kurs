# Ordlista

status: draft

| Begrepp | Kursens betydelse | Förväxla inte med |
|---|---|---|
| Ideologi | Sammanhängande värden och föreställningar om samhälle och makt | En enda sakpolitisk åsikt |
| Strategi | Sätt att mobilisera stöd och vinna eller utöva inflytande | Ideologins mål |
| Värdering | Bedömning av vad som bör eftersträvas | Empirisk observation |
| Empiriskt påstående | Påstående som kan undersökas mot erfarenhet/data | Automatiskt säker kunskap |
| Negativ frihet | Frihet från ingrepp eller tvång | Faktiska resurser att handla |
| Reella möjligheter | Faktiska förutsättningar att kunna välja och handla | En obegränsad garanti för alla utfall |
| Institution | Varaktig regel eller organisation som formar handlande | Bara en byggnad eller myndighet |
| Effektkedja | Villkorad följd av mekanismer och anpassningar | Prognos utan belägg |
| Pluralism | Utrymme för skilda legitima intressen och ståndpunkter | Att alla faktapåståenden är lika väl belagda |
| Rättsstat | Maktutövning bunden av rättsliga regler och rättssäkerhet | Enbart många lagar |
| Extern effekt | Påverkan på andra som inte fullt återspeglas i en transaktion | Alla indirekta effekter |
| Utgiftsmultiplikator | Förändring i produktion i förhållande till förändring i offentliga utgifter | Garanterad överavkastning, skatteåterflöde eller nettovinst |
| Monetarism | Ekonomisk skola som betonar penningmängdens betydelse och penningpolitiska regler | All penningpolitik eller alla inflationsmål |
| Vinstutdelning | Överföring av vinst till ägare | Överskott som återinvesteras i verksamheten |
